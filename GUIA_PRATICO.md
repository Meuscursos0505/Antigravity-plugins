# 📘 Guia Definitivo para Iniciantes e Não Programadores

> **"Não sei programar. Como este repositório me ajuda e como eu uso tudo isso?"**

Se você não é programador, pense neste repositório como uma **superloja de manuais de instrução, especialistas virtuais e ferramentas profissionais** para a sua Inteligência Artificial (Antigravity).

Por padrão, a IA é inteligente, mas pode esquecer etapas, cometer erros básicos ou inventar coisas. **Este repositório ensina a IA a agir como uma equipe inteira de engenheiros de elite.**

---

## 🧠 1. Entendendo os Conceitos de Forma Simples

Para entender o que tem aqui dentro, pense em uma oficina:

| Conceito | O que significa na prática? | Analogia do mundo real |
| :--- | :--- | :--- |
| **Plugin** | É uma **maleta temática fechada**. Cada maleta contém tudo o que é preciso para um trabalho específico (ex: maleta de conserto elétrico, maleta de pintura). | Uma caixa de ferramentas completa para uma área. |
| **Skill (Habilidade)** | É o **manual passo a passo detalhado**. Ele proíbe a IA de chutar e a obriga a seguir uma receita comprovada antes de te responder. | Uma receita de chef de cozinha ou um checklist de aviação. |
| **Subagente** | É um **especialista temporário** que a IA principal contrata para fazer um trabalho focado sem se distrair. | Contratar um arquiteto apenas para desenhar a planta, e depois um auditor apenas para achar falhas. |
| **MCP (Model Context Protocol)** | É o **cabo de conexão**. Ele dá "mãos e olhos" para a IA poder mexer no seu navegador, no seu GitHub ou nos seus arquivos. | Um cabo USB que conecta o robô aos seus aplicativos. |

## 🎯 2. Como esse Repositório te Ajuda no Dia a Dia?

Mesmo sem escrever uma única linha de código, você pode pedir coisas complexas em português comum e a IA usará estes plugins para resolver:

### Exemplo 1: Você tem uma ideia de aplicativo ou site
* **O que você diz:** *"Quero criar um aplicativo de lista de compras simples."*
* **O que acontece nos bastidores:** O plugin **`feature-dev`** acorda. Ele aciona um **arquiteto** para desenhar o plano, faz perguntas para entender o que você quer, cria os arquivos e depois aciona um **revisor** para garantir que tudo funciona.

### Exemplo 2: Algo deu errado ou seu código quebrou
* **O que você diz:** *"Olhe meu código e descubra por que ele não está funcionando."*
* **O que acontece nos bastidores:** O plugin **`code-review`** e o **`code-simplifier`** entram em ação. Eles caçam erros lógicos, removem código inútil e corrigem o problema sem estragar o restante.

### Exemplo 3: Você quer testar se um site abre e clica de verdade
* **O que você diz:** *"Abra o meu site e teste se o botão de login funciona."*
* **O que acontece nos bastidores:** O plugin **`playwright`** (via MCP) abre um navegador de verdade, clica nos botões e te conta se funcionou.

## 🚀 4. Passo a Passo: Como Instalar e Começar a Usar

Se você já baixou ou clonou este repositório, basta seguir 3 passos rápidos:

### Passo 1: Abrir o terminal
No seu Windows, abra o **PowerShell** (ou terminal).

### Passo 2: Executar a instalação automática
Vá até a pasta do projeto e instale todos os plugins de uma vez com o comando:

```powershell
cd C:\Users\Th3_R0nn3r\.gemini\antigravity\scratch\antigravity-plugins
.\install.ps1 -All
```

> **O que esse comando faz?** Ele copia automaticamente os 57 plugins para a pasta de inteligência do seu Antigravity (`.gemini/config/plugins/`). Você não precisa configurar nada manualmente.

### Passo 3: Usar diretamente no seu chat
Abra seu chat no Antigravity e simplesmente converse com a IA!

Você pode pedir:
* *"Quais plugins você tem instalados?"*
* *"Ative o feature-dev para criarmos um jogo simples de adivinhar números."*
* *"Use a skill de frontend-design para refatorar o visual do meu botão."*

## ❓ 5. Perguntas Frequentes (FAQ)

#### Preciso entender de linguagens de programação?
**Não.** Os plugins servem justamente para orientar a IA a fazer o trabalho técnico duro por você, com alto padrão de qualidade, enquanto você apenas orienta a ideia e os objetivos.

#### A IA sabe quando usar cada um?
**Sim.** Quando os plugins estão instalados, a IA do Antigravity lê a descrição de cada um e decide automaticamente quando acionar a habilidade certa para o que você pediu.

#### O que fazer se uma ferramenta como GitHub ou Playwright pedir login?
A IA vai te avisar de forma simples e te dar o link exato onde você só precisa clicar e autorizar com sua conta.
