# Plugin `siteantigravity`

Orquestrador definitivo para criação de sites de classe mundial no **Antigravity**.

Ele coordena automaticamente:
1. 🏗️ **Planejamento** (`feature-dev`)
2. 🎨 **Design Visual Awwwards** (`sitealtonivel` + `frontend-design`)
3. ⚡ **Construção Limpa** (`typescript-lsp`)
4. 🧪 **Testes no Navegador** (`playwright`)
5. 🛡️ **Pente Fino & Auditoria** (`code-simplifier` + `security-guidance` + `code-review`)
6. 🚀 **Salvamento & DevOps** (`commit-commands`)

## Como Usar

No chat do Antigravity, basta digitar:
```bash
/siteantigravity Crie uma landing page para uma plataforma de IA moderna
```
